# Housing crash predictor

# What is this:
An ML practice project that simulates predicting housing market crash risk using synthetic economic data. It demonstrates how machine learning models can analyze economic indicators and estimate the likelihood of a housing market downturn.

# How to test:
1. Setup environment
python3 -m venv env
source env/bin/activate

2. Install requirements:
pip install -r requirements.txt
    
3. Run: python app.py
